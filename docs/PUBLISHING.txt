--- PREREQS ---
USE NODE AND NPM FROM THE PROJECT ENVIRONMENT.
RUN COMMANDS FROM THE SITE ROOT.
KEEP THE DEV SERVER AVAILABLE FOR DRAFT PREVIEW WHEN WRITING.
POST FILES LIVE IN content/posts/.
IMAGES FOR A POST LIVE IN public/blog/img/SLUG/.

--- CREATE DRAFT ---
RUN: npm run new-post
ENTER THE TITLE, TAGS, AND DESCRIPTION.
THE SCRIPT CREATES content/posts/SLUG.mdx AS draft: true.
THE SCRIPT ALSO CREATES public/blog/img/SLUG/ FOR POST ASSETS.

--- WRITE ---
USE content/posts/_TEMPLATE.mdx AS THE REFERENCE STRUCTURE.
KEEP THE FRONTMATTER FIELDS COMPLETE: title, date, slug, description, tags, draft.
MAKE SURE slug MATCHES THE FILENAME EXACTLY.
KEEP description AT 160 CHARACTERS OR LESS.
KEEP tags LOWERCASE AND BETWEEN 1 AND 5 TOTAL.

--- PREVIEW ---
START THE DEV SERVER WITH: npm run dev
OPEN: http://localhost:5173/blog/SLUG
CONFIRM THE COPY, IMAGES, CODE BLOCKS, AND HEADINGS RENDER CORRECTLY.

--- VALIDATE ---
THE POST INDEXER NOW VALIDATES FRONTMATTER WHILE BUILDING.
CHECK FOR ERRORS IN THE FORMAT: filename:fieldname — reason
SHORT DESCRIPTIONS UNDER 50 CHARACTERS OR LONG ONES OVER 155 CHARACTERS ONLY WARN, BUT THEY SHOULD STILL BE FIXED.

--- PUBLISH ---
RUN: npm run publish-post -- SLUG
IF THE POST IS STILL A DRAFT, CONFIRM THE PROMPT TO FLIP draft TO false.
THE SCRIPT RUNS THE FULL BUILD, PRINTS LOCAL PREVIEW INFO, AND CAN OPTIONALLY STAGE AND COMMIT THE POST.
THE SCRIPT NEVER PUSHES.

--- PUSH ---
AFTER THE LOCAL COMMIT, RUN: git push
ONLY PUSH AFTER THE BUILD SUCCEEDS AND THE POST LOOKS CORRECT.

--- COMMON ERRORS ---
SLUG MISMATCH: RENAME THE FILE OR FIX slug SO THEY MATCH EXACTLY.
BAD DATE: USE YYYY-MM-DD AND MAKE SURE IT IS A REAL CALENDAR DATE.
DESCRIPTION TOO LONG: CUT IT TO 160 CHARACTERS OR FEWER.
INVALID TAGS: USE 1 TO 5 LOWERCASE TAGS.
DRAFT NOT BOOLEAN: USE draft: true OR draft: false WITH NO QUOTES.
SERIES INVALID: IF USED, SET series.name TO TEXT AND series.order TO A NUMBER.

--- FILES-NOT-TO-EDIT ---
DO NOT HAND-EDIT src/lib/blog/posts.generated.json.
DO NOT PUBLISH content/posts/_TEMPLATE.mdx AS A REAL POST.
DO NOT HAND-EDIT GENERATED OG IMAGES IN public/blog/og/ UNLESS YOU ARE REPLACING THEM INTENTIONALLY.

--- REVERTING ---
IF THE POST IS UNCOMMITTED, RUN: git restore content/posts/SLUG.mdx
IF YOU STAGED THE GENERATED INDEX TOO, RUN: git restore --staged content/posts/SLUG.mdx src/lib/blog/posts.generated.json
IF YOU ALREADY COMMITTED, RUN: git revert HEAD
IF YOU FLIPPED draft TO false BY MISTAKE, CHANGE IT BACK TO draft: true AND RE-RUN THE BUILD LATER WHEN READY.
